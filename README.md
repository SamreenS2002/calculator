# 🧮  Calculator
A containerized Flask web application built with a focus on precision, reproducibility, and clean architecture.

## 🚀 Live Demo
Check out the live application here: https://calculator-bann.onrender.com/
## 🛠 The Tech Stack
* **Backend:** Python 3.12 with Flask
* **Environment:** Docker (Containerized for consistent deployment)
* **CI/CD:** GitHub Actions & Render
* **Frontend:** HTML5 & CSS3

## 🏗 Project Architecture
This project follows a standard Flask structure, containerized to ensure it runs perfectly in any environment without "it works on my machine" issues.
